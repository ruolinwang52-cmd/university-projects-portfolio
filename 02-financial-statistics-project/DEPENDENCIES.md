# MATLAB dependencies

The three project scripts contain the project-specific model, filtering, optimisation, risk, and evaluation functions at the end of each file. The following course-supplied resources are required for complete reproduction but are not redistributed in this public portfolio:

| Resource | Used by | Reason not included |
| --- | --- | --- |
| `VOLV0A.mat` | `Project_Part1.m` | Course-supplied market dataset |
| `OMXS30optA.mat` | `Project_Part2.m` | Course-supplied option dataset |
| `MLmax.p` | Parts 1 and 3 | Compiled course helper; source and redistribution licence unavailable |
| `opt_price.p` | Part 2 | Compiled course pricing helper; source and redistribution licence unavailable |
| `lnl_spec.m` | Parts 1 and 3 | Explicitly copyrighted course helper |

`ASSETSA.csv` and `ASSETSB.csv`, required by Part 3, are included. The report contains the complete methodology and results for all three parts.
