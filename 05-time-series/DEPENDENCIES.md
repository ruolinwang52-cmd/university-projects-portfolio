# MATLAB dependencies

The main project workflow is included as `project.m`. It uses MATLAB's System Identification Toolbox and Statistics and Machine Learning Toolbox, plus the following teaching-library functions supplied with the course:

- `acf.m`
- `bcNormPlot.m`
- `checkIfNormal.m`
- `checkIfWhite.m`
- `corrM.m`
- `countSignChanges.m`
- `dagostinoK2test.m`
- `equalLength.m`
- `estimateARMA.m`
- `estimateBJ.m`
- `lbpTest.m`
- `mlTest.m`
- `montiTest.m`
- `pacf.m`
- `plotACFnPACF.m`
- `plotCumPer.m`
- `plotWithConf.m`
- `polydivision.m`
- `predictARMA.m`
- `predictBJ.m`
- `whitenessTest.m`

These functions reference the course text *An Introduction to Time Series Modeling* by Andreas Jakobsson or form part of the associated teaching library. They are listed for reproducibility but are not redistributed because no public reuse licence was supplied. The project dataset `projectData24.mat` is included.
