# Stationary Stochastic Processes

## Quick overview

Python lab work on estimating and interpreting stochastic-process properties in simulated, audio, sunspot, and EEG signals.

## Topics covered

- Estimation of mean and covariance functions
- Spectral density and periodogram analysis
- ARMA process simulation
- Sampling, aliasing, and filtering
- Spectrograms and frequency-domain analysis
- Applications to audio, sunspot, and EEG data

## Files

- `pythonLab1.ipynb`, `pythonLab2.ipynb`, `pythonLab3.ipynb` — notebook-based analyses
- `lab-1.py`, `lab-3.py` — script versions of selected exercises

## Skills demonstrated

NumPy, SciPy signal processing, spectral analysis, stochastic modelling, scientific plotting, and interpretation of real signals.

## Reproducibility note

The notebooks refer to course-supplied `.mat` signal datasets and helper functions that are not redistributed here.
