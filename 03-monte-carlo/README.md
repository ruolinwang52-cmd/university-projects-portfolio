# Monte Carlo and Empirical Methods

## Quick overview

Three collaborative assignments applying simulation and Bayesian computation to wind-power estimation, self-avoiding random walks, and change-point analysis of coal-mine disaster data.

## Assignment map

- **Assignment 1:** random-number generation, wind-power estimation, confidence intervals, truncation, and importance sampling.
- **Assignment 2:** sequential importance sampling for self-avoiding walks and particle-based simulation methods.
- **Assignment 3:** Bayesian piecewise-Poisson change-point modelling with Gibbs and Metropolis-Hastings updates, plus extreme-value estimation.

## Files

- `assignment-1-report.pdf`, `assignment-2-report.pdf`, `assignment-3-report.pdf` — derivations, experiments, results, and discussion
- `proj1-1.m`, `proj2.m`, `proj3.m` — main MATLAB implementations
- `est_gumbel.m`, `posterior.m` — supporting estimation functions
- `atlantic.txt` — data used in the extreme-value analysis

## Skills demonstrated

Monte Carlo simulation, variance reduction, importance sampling, particle methods, MCMC, Bayesian inference, uncertainty quantification, and reproducible computational reporting.
