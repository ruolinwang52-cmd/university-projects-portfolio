# Matrix Computation

## Quick overview

MATLAB exercises for detecting integer eigenvalues, analysing null-space growth, and constructing Jordan normal forms algorithmically.

## Files

- `heltalsev.m` — integer-eigenvalue and multiplicity helper
- `jordanmatris.m` — Jordan-block construction from eigenvalue multiplicities and null spaces
- `testmatris.m` — test cases
- `lab1.m` — accompanying lab entry point
- [`DEPENDENCIES.md`](DEPENDENCIES.md) — completeness check and standard MATLAB requirements

## Skills demonstrated

Eigenvalue analysis, null spaces, Jordan structure, numerical tolerances, MATLAB function design, and algorithmic translation of linear-algebra theory.
