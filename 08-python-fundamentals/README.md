# Python Fundamentals and Numerical Programming

## Quick overview

Early university programming work demonstrating the progression from core Python exercises to numerical algorithms and a custom interval-arithmetic class.

## Selected work

- Logarithm approximation and convergence visualisation
- Interval arithmetic with operator overloading and input validation
- Introductory numerical-programming exercises
- Numerical experimentation in Jupyter

## Files

- `homework1.py` — iterative logarithm approximation and convergence analysis
- `homework2.py` — collaborative interval-arithmetic implementation
- `ln_approx.ipynb` — notebook exploration of logarithm approximation
- `unit1.py`, `unit2.py`, `assignment2.py` — smaller programming exercises

## Skills demonstrated

Python fundamentals, NumPy, object-oriented programming, numerical precision, validation, plotting, and iterative algorithms.
